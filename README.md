# 帧析

在浏览器里把视频里的文字抽出来。字幕、标题、课件、包装上的字都可以。视频不会上传，拆帧和识别都在你自己的电脑上完成。

## 它做什么

1. 放入一个视频（mp4、webm、mov）。
2. 按每秒 5 帧把画面拆开。
3. 读出画面上的字，同一句会合并成一段，并带上时间和画面缩略图。
4. 可以复制全文，或下载 TXT、SRT。

可以只解析某一段（填写开始、结束秒数），也可以只看画面的底部字幕或顶部标题。

## 两种识别方式

| 引擎 | 适合 |
|---|---|
| 检测识别（默认） | 先框出每一行再识别，中文和英文更完整。同一句会用多帧结果投票。第一次要加载模型。 |
| 整页识别 | 整张画面直接交给 Tesseract，不单独找文字位置。 |

语言可选简体中文、繁体中文、英文、日文。整页识别时还可以选版面：自动、成块文字、零散文字。

## 本地运行

需要 Node.js 22.12 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:8080`。

Windows 上如果提示找不到 vite，先确认 Node 版本，再删掉 `node_modules` 和 `package-lock.json` 后重新 `npm install`。
